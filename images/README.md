# Photos & logos

Drop your real photos into this folder using the **exact filenames below**.
The site detects them automatically and replaces the labeled placeholder —
no code changes needed. Until a file exists, a labeled placeholder shows instead.

Tips: use landscape JPGs, ~1600px wide for full-width photos and ~1000px for
cards. Compress them first (free: https://squoosh.app) so pages load fast.
Only use photos you have permission to share, especially of minors.
